# MOEMOA 기록 템플릿 인덱스

> **문서 상태: `CURRENT TEMPLATE INDEX`**
> 템플릿은 결정·계획·검증을 기록하는 형식이며, 채워지지 않은 템플릿 자체는 승인이나 정책이 아니다.

| 템플릿 | 용도 |
| --- | --- |
| `DECISION_LOG_TEMPLATE.md` | 사용자 승인 제품·운영 결정 기록 |
| `EXEC_PLAN_TEMPLATE.md` | 여러 파일·migration·장기 구현 계획 |
| `SOURCE_REGISTRY_TEMPLATE.md` | catalog source 이용 조건·필드·승격 범위 기록 |
| `TASK_COMPLETION_REPORT_TEMPLATE.md` | 변경·검증·제약 완료 보고 |
| `TEST_EVIDENCE_TEMPLATE.md` | 명령·환경·결과·실패 증거 기록 |
| `UGC_LAUNCH_GATE_TEMPLATE.md` | Public/UGC 활성화 전 운영·권리·삭제 gate 기록 |

사용 시 파일을 복사해 `docs/moemoa/decisions/`, `docs/moemoa/plans/`, 승인된 registry/gate 위치에 새 기록을 만든다. 원본 템플릿에 실제 결정을 직접 누적하지 않는다.
