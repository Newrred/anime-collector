# 휴대폰 Web 확인 — 테스트 서버 전용

기존 W19의 실제 기기 확인 절차다. Android 앱·정식 출시 검사가 아니다. iPhone Safari와 Android Chrome에서 각각 수행한다.

- 테스트 주소: https://anime-collector-git-codex-phone-test-newrreds-projects.vercel.app/data/
- 배포 보호가 표시되면 Codex가 제공한 한시적 공유 링크로 먼저 접속한다. 운영 `moemoa.xyz`와 데이터가 분리된 테스트 서버다.
- 이미지: https://anime-collector-git-codex-phone-test-newrreds-projects.vercel.app/test-assets/phone-test.png
- 범위: `codex/phone-test` Preview 전용, `moemoa-test` 프로젝트. 이미지10개/40MiB·신고 일일10건의 시험 한도다. 24시간 뒤 업로드 정책이 만료되면 반복하지 말고 알려준다.

## 확인 순서 (기기당 약 5~10분)

1. 제공한 테스트 링크를 Safari/Chrome에서 직접 연다. 카카오톡 등의 앱 내부 브라우저는 피한다.
2. 설정 → 계정·데이터에서 기존 테스트 Google 계정으로 로그인한다. 로그인 후 테스트 사이트로 돌아오는지 확인한다.
3. 제공된 합성 이미지 `test-assets/phone-test.png`를 사진첩/파일에 저장한다. 기억 추가에서 작품과 이 파일을 선택하고 `폰 테스트 - 기기명`으로 저장한다. 사진 선택 취소도 한 번 확인한다. 개인 사진·애니 캡처·타인 그림은 사용하지 않는다.
4. 카드에서 비공개 이미지 동기화를 선택·확인한다. 계정·데이터에서 동기화를 마친 뒤 다른 기기에서 같은 계정으로 로그인·동기화하고 카드와 이미지가 보이는지 확인한다.
5. 테스트 보드에 카드 하나를 넣는다. 공개할 카드를 직접 선택하고 테스트 합성 이미지의 공개 사용을 확인한다. 미리보기에서 확인한 뒤 게시한다.
6. 공유 링크를 다른 브라우저/비공개 탭에서 열어 제목과 이미지가 보이는지 확인한다. 원래 화면에서 보드를 철회한 뒤 방문자 페이지를 새로고침하면 보이지 않아야 한다.
7. 입력 중 키보드가 저장 버튼을 가리지 않는지, 화면이 옆으로 밀리거나 버튼이 눌리지 않는지 확인한다.

공개 준비가 실패하면 반복 탭하지 말고 오류 문구와 단계만 알려준다. 원본과 미완료 요청을 임의 삭제하지 않는다. 실제 계정 비밀번호·인증코드·개인 사진은 보고에 넣지 않는다.

## 결과 전달

`기기/브라우저: 로그인 O/X, 사진 선택·저장 O/X, 다른 기기 동기화 O/X, 게시·익명 열람 O/X, 철회 O/X, 화면 문제(없음/단계·증상)`

사용자가 직접 확인하기 전 모든 실기기 항목은 미검증이다. 종료를 알려주면 테스트 설정과 한시 권한을 원복하고 이번 합성 자료만 정리한다. 운영 자료를 삭제하지 않는다.
