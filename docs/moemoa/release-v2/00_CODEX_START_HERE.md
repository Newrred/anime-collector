## 이번에 고정하는 목표

**개인 기록 + 계정 기반 사용 + 공개 보드 + 공개 미니홈 + 팔로우 + 최소 운영·관리**를 첫 정식 출시의 한 묶음으로 완성한다.

사용자 A가 기억을 남기고 일부를 보드·미니홈에 공개한다. 비로그인 방문자가 선택된 내용만 보고, 사용자 B가 A를 팔로우해 나중에 다시 방문한다. A와 관리자는 공개를 철회할 수 있고, 운영자는 제한·신고 처리·갱신·복구를 수행할 수 있다.

Guest/Private-only는 중간 테스트 상태일 뿐, 이 목표의 완료 대안이 아니다. Public은 작업 중 안전한 격리 환경에서 개발하고, 최종 운영 활성화는 출시 승인 뒤에 한다.
