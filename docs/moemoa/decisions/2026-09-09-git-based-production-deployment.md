# Git 기반 운영 배포

상태: 사용자 확정, 2026-09-09.

사용자 지시: “앞으로는 헷갈리지 않게 git을 통해 배포해줘.”

운영 웹 배포는 `Newrred/anime-collector`의 production branch `master`에 검토된 코드를 커밋·push하고 Vercel Git 연동으로 생성된 배포를 검증한다. 커밋 SHA와 운영 deployment ID를 함께 기록한다. 로컬/CLI 직접 배포·승격은 그 배포에 대한 사용자 명시 예외 승인 없이 사용하지 않는다. 데이터의 운영 적용은 별도이며, 재현용 코드·마이그레이션·릴리스 기록을 Git으로 관리하되 자격증명·개인 데이터는 올리지 않는다.

이 결정은 과거 미커밋 변경이 자동 push됐다는 의미가 아니다. 2026-09-09 Pro 검토 패키지에는 GitHub와 로컬 코드의 차이를 명시하고 최신 코드 스냅샷을 제공한다.
