# 226건 실데이터 검토·운영 반영

사용자가 명확히 요청한 범위는 코드가 아니라 증분 226건의 개별 검토와 데이터 배포다. 2026-09-07 후속 ㅇㅋ 승인으로 실행한다.

1. 저장된 AniLife 원본/cover, AniList enrichment binding/원본, canonical/projection을 각 행의 hash에 연결해 검토한다. seed에 AniList ID가 없다는 사실과 canonical에 ID가 없다는 사실을 구분한다.
2. 기존 운영 3,999건 snapshot과 226건 내부의 source ID, 원어 제목, 시즌·형식·연도, 표지 hash/유사도를 대조한다. 60FPS/자막 변형은 새 작품으로 게시하지 않는다. 중복은 원본 삭제 없이 게시 제외와 연결 기록으로 남긴다.
3. 증거가 부족하거나 서로 모순되는 후보는 추가 출처 확인 후 교정/보류한다. 모든 226건에 게시/중복/보류 판정과 근거를 남긴다. 원본 증거는 보존한다.
4. 승인 후보만 새 DB release로 추가한다. 기존 3,999행과 5등분 2기 보존을 snapshot/hash로 확인한다. AniLife provider 제약 migration을 필요한 시점에 검증·적용한다. 업로드 후 재조회/hash/표지 접근 확인을 통과해야 active pointer를 전환한다.
5. 실제 웹에서 신규 작품과 기존 5등분 1·2기 검색/상세/표지를 검증한다. 코드 배포는 필요한 수정이 있을 때만 수행한다.

롤백: 원본 release `catalog-add-81297cd638290f972ca84c28` 재활성화. 기존 release/원본/사용자 데이터 삭제 금지. 관리자 키는 프로세스 환경/기존 관리 인증으로만 읽고 로그·정적 파일에 출력하지 않는다. Public/사용자 이미지 업로드 범위는 변경하지 않는다.

최종 보고: 226건의 판정 합계, 실제 추가 수·최종 운영 수, 교정/제외/보류 이유, DB migration, 업로드/검증/복구 증거를 제공한다. 코드 배포만 하고 요청 완료로 보고하지 않는다.
