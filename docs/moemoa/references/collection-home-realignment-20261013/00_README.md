# MOEMOA — 컬렉션·미니홈·보드 관계 교정 패키지

2026-10-13 KST / 기준 `b0541fffb03c1e828feef21d3e38fa5caa335c07`

## 핵심

컬렉션을 개인 미니홈의 대표 공간으로 삼고, 그 안에 작품 선반과 기존 Memory 보드를 두 종류의 묶음으로 배치한다. 개인 원본과 공개 사본의 권한 경계는 그대로 유지한다. 현재 별도의 공개 시스템을 버리는 것이 아니라 사용자 공간·공개 작품 선반 계약·작업별 레이아웃을 교정한다.

## 읽는 순서

1. `01_REVIEW_AND_TARGET_SPEC.md`: 현재 사실, 사용자 의도, 권장 구조, 화면별 전후, 기능 보존과 데이터 영향.
2. `02_CODEX_EXECUTION_NOTE.md`: 기존 W/Q/D에 반영할 구현 명세와 수용 조건. 끝에 복사용 지시문.
3. `evidence/SOURCE_EVIDENCE.md`: 고정 소스 발췌와 관찰 근거.

기존 `release-v2/03_RELEASE_WORKBOARD.md`가 유일한 진행판이다. 이 패키지는 새 진행판·새로운 출시 단계 트리가 아니다.

## 실제 한 일

- 첨부 manifest447개 항목 검증, 불일치0.
- 선택 단위 검사9 PASS(2개 파일), 원본 모듈+합성 gateway 계약 관찰3건.
- 소스/문서/스크린샷 분석과 실행 명세 작성.

앱 코드를 수정하거나 전체 build/E2E/실서버·기기/배포를 실행하지 않았다. 과거 보고의 전체 검사 결과와 실제 운영 인수를 이번 독립 검증으로 합산하지 않는다. 현재 첨부는 선택 소스이며 전체 runnable clone이 아니다.

## 실행 관찰 재현

전체 저장소의 해당 기준 소스를 로컬에 준비한 후:

```bash
node evidence/reproduce-contracts.mjs /path/to/anime-collector /tmp/observations.json
```

이 관찰은 정상 제품 동작을 모두 인증하는 test suite가 아니다. 새로운 제목 선반 계약과 기존 편집 초기값의 전달을 확인하는 한정된 검사다. 원본 저장소 파일을 변경하지 않고 합성 자료만 사용한다.

## 제외

원본 사용자 사진·로그·비밀키·폰트는 포함하지 않는다. 이전 디자인 비교84PNG는 입력 ZIP에 없었고 이 패키지에도 없다. 현재 자료로 확인하지 못한 화면은 직접 보았다고 주장하지 않는다.
