# 현재 디자인 — Are.na 재검토 반영 (13차)

사용자 요청으로 아래12차 장식 규칙을 교체했다. 현행은 얇은58px상단, 작은평면버튼/모서리2px, 그림자·절취선·핑크채움 없음,24px 제목, 가는선과 중립면. Pink는 선택/초점/주요행동 텍스트. 상세 동작/모델은 유지. 아래 원형/절취선/7px버튼 설명은12차 이력이며 현재 규칙이 아니다.

참고한 실제 페이지: https://www.are.na/explore (10/5 Chromium1440에서 콘텐츠 로드 확인). 별도 typography 채널은 skeleton 상태로 버튼/nav 수치만 관찰했고 실제 카드레이아웃 근거로 쓰지 않았다. nav55px·shadow0·버튼radius3px·제목28px는 관찰치. MOEMOA58px·2px·24px/6열은 적용 제안치이며 그대로 복제했다고 주장하지 않는다. Are.na 이미지/폰트/로고는 가져오지 않았다.

## 이번 화면에서 확인할 것
1. 최초 책장: 로고/메뉴/기억 남기기 위계, 선반 선택 탭, 표지 제목·기록수·날짜·한 줄 감상.
2. 표지 클릭: 한 행 아래 필름. 얇은 선/빈 구멍 장식, 작품 제목·기억수·접기, 장면 캡션·이동·추가 버튼.
3. 제목 옆 점3개: 책장 꾸미기/전체 작품 보기. 바깥 클릭·Escape로 닫기.
4. 책장 꾸미기: 이름 입력, 선반 이름, 진열 순서·제거·작품 선택, 적용/취소, 꾸미기 미리보기. 진열 해제가 기억 삭제가 아니라는 안내 유지.
5. 모든 진열 해제: 작은 빈 상태와 작품 다시 고르기. Hero/빈 상태 배너 없음.

## 구체적인 스타일
- 주요 행동만 #E60068, 호버 #CE005D. 흰 바탕/얇은 중립 구분선, 선택 탭은 아주 옅은 핑크.
- 제목20px/650(모바일18), 표지 제목14/600(모바일12), 메타11(모바일10), 감상12(모바일11). 모바일 글자 확대 검증은 후속이며 해당 소형 메타 크기는 미감 검토 후보다.
- 주요 버튼: 아이콘 구획과 절취선, 모서리7px,2px 단면. 보조 버튼6px, 이동/접기44px 원형.
- 표지는 확대하지 않으며 선택 외곽선만2px. 필름은 자연 이미지 비율 유지.
- 편집 메뉴244px, 항목44px, 바깥 여백6px. 입력44px/모서리6px, 편집기10px, 각 조작에 명시적 이름.
- 접기는 모바일 필름 헤더에 배치해 하단의 이전/다음/추가가 불필요하게 분리되지 않도록 했다.
- 가상 데이터에 대한 선택/취소/적용만 실제 동작한다. 새 백엔드 기능·저장 계약 없음.
