# AD_Direzione 분석과 MOEMOA 구조 시안

2026-10-05. 기준: https://www.are.na/chase-body/ad_direzione . 사용자가 보낸 가로 캡처의 영역을 실제 브라우저에서 로드하고 조작했다. 소개 페이지나 skeleton을 완성된 채널 구조로 대신하지 않았다.

## 무엇을 놓쳤었나
이전 시안은1440에서도6열, 표지를2:3셀 전체에 채우고 제목 아래 바로 나열했다. 지정 채널은 같은 폭에서4열, 정사각형 이미지 무대에 원래 비율을 유지하고, 상단에 제목/정보/연결/보기를 별도 계층으로 둔다. 버튼 모양만 바꿔서는 비슷해질 수 없는 차이였다.

## 실제로 관찰한 행동
1. 정보의 Reveal More:잘린 연결정보가 펼쳐지고 아래 목록의Y가 이동한다. 별도의Hero가 생기지 않는다.
2. More:처음Loading, 이후Flag as inappropriate/Present/API/RSS. 소유자편집 메뉴를 확인한 것은 아니다. 연결/신고·유료조작은 실행하지 않았다.
3. Grid→Table:/table 경로로 이동하지만 익명 상태에서는Premium 안내. 실제표 내용·정렬방식은 확인 불가. MOEMOA 표는 자체제안이며Are.na구현을 그대로 복제했다는 뜻이 아니다.
4. Search this channel:채널범위가 지정된 검색대화상자. 전역명령/페이지 탐색도 포함. 새 시안은 책장내작품/감상검색만 실제동작하며 복합명령/전체서비스검색은 제외.
5. 블록: /block/41971491로 이동하면서 큰 이미지와 우측메타정보를 가진대화상자가열림. 배경채널유지, 상단이전/다음/닫기, 연결/댓글 영역. MOEMOA는기억이미지·날짜·감상·작품이동만 연결. 댓글/공개연결을 새로 추가하지 않았다.
6. 스크롤/hover:해당폭의 격자 유지, 이미지에 부가조작이 드러남. 약1.6k자료의원본은 가상스크롤을 사용하는 것으로DOM padding에서 추정되지만 전체데이터/성능을 검증하지 않았다.
