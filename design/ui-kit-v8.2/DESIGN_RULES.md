# MOEMOA V8.2 — 서비스 적용 준비안

2026-10-05 · 검토용. V8의 필름책장을 유지하는 작은 보완이며 최종 승인·운영 반영을 의미하지 않는다.

## 고정할 기준
- Hero/환영 배너/자동 펼침 없음. 로고2안과 표지 6/4/3/2열, 선택 행 아래 패널 하나 유지.
- 표지의 위치·크기는 선택/hover로 움직이지 않는다. 그림 자체 확대·유색 여백·자동 필름 넘김 금지.
- 개인 책장의 진열 합집합과 전체 작품 목록은 다르다. Board N:M·Memory·WatchLog 모델은 변경하지 않는다.
- 서비스의 생동감은 조작에 대한 응답으로 만든다. 숫자·온라인 표시·저장 완료를 임의로 꾸며내지 않는다.

## 버튼·아이콘 계약
주요 행동은 화면/대화상자별 하나를 먹색 채움으로 표시한다. 일반 행동은 흰색 테두리, 접기·보조 이동은 텍스트, 삭제는 오류색 텍스트다. 검색/닫기 등 익숙한 아이콘 외에는 라벨을 함께 쓴다.

아이콘28종은 24px viewBox, 선2px, 둥근 끝/이음이다. 로고의 필름 구멍 장식을 모든 화살표에 반복하지 않는다. film/shelf만 브랜드 의미를 담고 나머지는 표준적으로 읽히게 한다. SVG 원본과 먹색/회색/흰색/강조색의24·48·72px 투명 PNG336개 제공. 24px 표시에는48px(2x),72px(3x)를 쓴다. 흰색은 어두운 버튼 전용. 흐릿한 disabled는 런타임 opacity로 처리한다.

buttons/*.png는 상태별 외관 견본5개다. 가로선은 텍스트 자리 표시이며 실제 라벨이 아니다. 실제 버튼 전체를 이미지로 구현하지 않는다. 라벨은 HTML 텍스트로 번역·확대 가능하게 두고 아이콘은 장식일 때 alt=""를 쓴다. 아이콘 전용 버튼에는 aria-label을 지정한다. 원본 생성 방식은 AI 그림 생성이 아닌 자체 SVG 도형의 sharp 래스터화다.

## 덜 정적인 반응
| 행동 | 반응 | 제한 |
|---|---|---|
| 버튼 hover/press | 배경120ms / 누름2px·80ms | 표지에는 transform 사용 안 함 |
| 표지 선택 | 선택 라벨·초점 명확화, 필름180ms/4px 등장 | 기존 행 위치/폭 보존, 자동 스크롤 강요 금지 |
| 필름 이동 | 이전/다음44px 버튼·키보드 지원 | 스와이프가 유일한 조작이 되면 안 됨 |
| 준비/저장 | 즉시 ‘준비 중…’, 중복 제출 방지, 버튼 옆 role=status | 서버 확인 전 성공 표시 금지 |
| 확정 성공 | 체크 + ‘준비됐어요’, 다음 미리보기 행동 | 화면 상단의 멀리 떨어진 toast에만 의존 금지 |
| 확정 실패 | 같은 위치에 이유·‘다시 시도’ | 입력/선택/원본·operationId 보존 |
| 결과 불확실 | ‘결과를 확인하지 못했어요’ + 상태 확인 | 새 operationId로 재업로드 금지 |
| 선택 탭/빈 상태 | aria-pressed와 underline, 짧은 다음 행동 | 색만으로 상태 전달 금지 |

prefers-reduced-motion에서는 회전·이동·전환을 제거하고 상태 텍스트를 유지한다. 로딩 shimmer/자동 캐러셀/수집수 pulse는 넣지 않는다. 모션은 정보와 행동의 연결에만 쓴다.

## 서비스에 적용할 순서
1. 공통 버튼/아이콘/초점 토큰을 기존 컴포넌트에 연결. 기존 동작·문구 key 유지.
2. MemoryPublicationPanel의 이미지 준비 한 흐름에 진행/성공/확정 실패/불확실 상태 적용. 실제 서버 상태를 그대로 표현하고 quota/재시도 계약 유지.
3. 책장 표지→필름→기억 상세의 단일 흐름에 V8 구성 이전. 정적 시안 CSS 전체를 붙이지 않고 공통 컴포넌트화.
4. 기존 홈/Archive/Board/작품 화면으로 확장. 각 화면 빈 상태·loading·error·권한 없음·긴 제목·키보드·320px·200% 확대 확인.

## 검토 파일과 실행
- index.html: 아이콘 목록, 버튼 상태 체험. 성공/실패는 명시적인 시뮬레이션이다.
- v8-refined.html: 기존 V8의 데이터/동작 코드를 재사용한 작은 시각 보완. DB와 연결하지 않는다.
- tokens.css: 신규 UI 계약 견본. 서비스 전체에 자동 적용하지 않는다.
- generate.mjs: 기존 sharp로 원본 재생성. `node design/ui-kit-v8.2/generate.mjs`.
- serve.mjs: `node design/ui-kit-v8.2/serve.mjs`, http://127.0.0.1:4351/ui-kit-v8.2/index.html

실제 서비스·인증·공개·동기화·배포는 변경하지 않았다. 실폰/Safari/스크린리더 검증과 최종 미감 승인은 남아 있다.

## 아이콘 연결표
- 기억 남기기: plus / 작품 탐색: search / 책장: shelf / 필름: film / 목록 배치: grid.
- 이전·다음 장면: arrow-left/right. 패널 펼침·접기: chevron-down/up. 외부 링크에만 arrow-up-right.
- 편집: edit / 선택 해제·dialog 닫기: close / 확인: check / 추가 메뉴: more.
- 이미지: image / 비공개: lock / 공개: globe / 신고: report / 삭제: trash.
- bookmark와 heart는 기존 기능 의미가 있는 곳에서만 사용. 아이콘을 만들었다고 새 저장·좋아요 기능을 추가하지 않는다.
- spinner는 준비 중에만 사용. retry는 확정 실패, info는 결과 불확실 상태에 대응.

추가 납품: `buttons-labeled/`에 실제 한국어 라벨을 넣은 3x 버튼 PNG6개. `node design/ui-kit-v8.2/render-buttons.mjs`로 재생성한다. 시각 참고용이며 실제 서비스에서는 텍스트 버튼을 사용한다. 모형 견본5개와 구분한다.
검증 재현: 서버 실행 후 `node design/ui-kit-v8.2/verify.mjs`. 결과는 verification.json. 1440/320 Chromium 화면, 28아이콘, 준비 성공·실패·불확실 후 조회, 표지 좌표/폭 유지, 가로 넘침0, reduced-motion 0s를 검사한다.

## 필름 선 장식 보완
사용자 요청으로 회색/먹색 필름 면을 제거했다. line-film.css에서 투명 프레임,1px 상하 윤곽선, 속이 빈 작은 필름 구멍을 사용한다. 이미지 위 덮개/색조 없음. 다음 장면 영역도 흰 배경으로 맞췄다. 핑크는 선택/주요 행동에 유지한다.
